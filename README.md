# ShiftingPort
My project is ShiftingPort, a full-stack packers and movers website developed to help customers explore relocation services and submit moving enquiries. The frontend is built using React, JavaScript, HTML, and CSS, with React Router DOM for navigation and Redux Toolkit with RTK Query for API communication. The backend is developed using PHP and Laravel, while MySQL/MariaDB is used to store application data. The website provides information about home shifting, office relocation, vehicle transportation, location-based services, blogs, offers, customer reviews, and shipment tracking. It includes a customer enquiry system through which users can submit their contact and moving details. The database manages information about services, states, cities, sublocations, pages, blogs, leads, and reviews. The backend also includes an administrative portal for managing website content and customer enquiries. This project helped me understand full-stack development, React component-based architecture, REST API integration, backend controllers, database relationships, and the interaction between frontend and backend systems.
